# GeNIe Software Updates

这是 GeNIe Software 的公开正式版更新仓库。

## 用途

- 只发布 Windows 安装包 Release。
- 不存放主程序源码。
- 给普通安装用户提供“正式版”更新通道。

## 下载方式

打开 Releases 页面，下载最新的 Windows x64 安装包：

```text
GeNIe-Software-Setup-版本号-x64.exe
```

安装完成后，从桌面快捷方式或开始菜单打开 `GeNIe Software`。

## 更新通道

- 正式版：读取本公开仓库，适合普通用户。
- 测试版：读取私有源码仓库 `YGrious/GeNIe-software`，适合内部测试。

软件内可在 `关于软件` 页面切换更新通道、检查更新并下载安装包。

## 注意

安装包不包含 GeNIe/QGeNIe 本体、PySMILE 商业许可证或任何 API Key。首次使用时，请在软件界面中检测或配置本机 GeNIe 安装目录。
